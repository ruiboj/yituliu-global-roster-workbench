# Changelog

All notable changes are documented here. This project follows semantic versioning where practical.

## 3.1.1 - 2026-09-07

- Added bilingual Yituliu token setup instructions and a Personal Center screenshot.
- Made the repository and release downloads public.
- Updated the bundled documentation and vulnerability reporting instructions.

## 3.1.0 - 2026-09-07

- Added a Windows x64 portable release with bundled Node.js and first-run public-data download.
- Added Start.cmd and Update-catalog.cmd, with automatic browser opening.
- Added annotated screenshots and rewrote the English and Chinese usage guides.
- Preserved the previous catalog when a refresh fails before replacement.
- Configured private GitHub publishing and repeatable portable release packaging.

## 3.0.0 - 2026-09-04

- Added Chinese/English interface switching without browser persistence.
- Expanded red risk warnings for whole-roster writes, tokens, drafts, OCR, public-data delays, popularity statistics, and ArkPRTS.
- Added GitHub CI, guarded release packaging, issue templates, security guidance, attribution, and bilingual documentation.
- Kept Global-server module availability filtering and E2 Lv.60 quick recommendations.

## 2.0.0 - 2026-09-04

- Rebuilt the local editor with the Neon Orange Workbench UI.
- Added skill/module names, popularity-based quick actions, MAA import, and optional ArkPRTS JSON import.
