# 一图流干员工作台

[English](README.md) · [下载 Windows 版](https://github.com/ruiboj/yituliu-global-roster-workbench/releases/latest)

给国际服玩家用的本地练度编辑器。导入 MAA 文件，补录专精和模组，再保存草稿。有一图流读写 Token 的用户也可以读取、写回一图流。

**导入、编辑、保存草稿都不需要 Token。** 本工具不会生成国服游戏 Token，也不会替你登录一图流。

![导入、编辑和备份的位置](docs/screenshots/workbench.png)

## 下载和启动

1. 在最新 Release 的 **Assets** 中下载 **Yituliu-Workbench-Windows-x64-v3.1.1.zip**。
2. 右键 ZIP，选择“全部解压”，打开解压后的文件夹。
3. 双击 **Start.cmd**。首次启动会下载公共游戏目录，完成后自动打开浏览器。
4. 使用期间保留命令窗口。退出前下载草稿，关闭命令窗口即可停止服务。

不需要安装 Node.js、输入命令、管理员权限或单独打开 HTML。运行包自带 Windows x64 的 Node.js 22。首次启动需要能访问 GitHub 和一图流；之后可用已下载目录离线编辑。远端读写和刷新统计仍需联网。

仓库和 Release 现已公开，下载 Windows ZIP 不需要 GitHub 账号。

## 使用步骤

1. **导入**：选择“导入 MAA OperBox”，打开 MAA 的 `Arknights_OperBox_Export.json`。按干员 ID 合并基础练度，保留已填的专精和模组。OCR 可能漏识别，导入后核对持有数量。手动录入时先取消“只看已持有”，再勾选你持有的干员。
2. **补录**：搜索中文名称或 charId，修改持有、精英化、等级、潜能、技能、专精和模组。右上角 EN / 中文切换工具语言；干员、技能、模组名称仍为中文。
3. **核对**：运行“完整检查”，处理错误。“推荐专三 / 推荐模组 3”会实际修改草稿，只在与你的真实练度相符时使用；统计表示投入率，不代表强度。设置专精、模组时可能自动补齐前置练度。
4. **保存**：点击“下载草稿”。下次通过“恢复草稿”继续。刷新或关闭页面会丢失未保存修改。

![练度编辑、检查和草稿按钮](docs/screenshots/editing.png)

## 获取一图流 Token

1. 登录你的**一图流账号**，打开[个人中心](https://ark.yituliu.cn/account/home)，或点击左侧菜单靠下的“**个人中心**”。
2. 在用户信息下方找到“**第三方 API Token**”卡片。
3. 点击“**生成只读 TOKEN**”，将生成的值复制到本工具的“**只读 Token**”输入框，用来读取你的一图流练度。
4. 如果需要把编辑结果保存到一图流，点击“**生成只写 TOKEN**”，将生成的值粘贴到“**只写 Token**”输入框。只有检查并最终确认写入后，工具才会使用它。

这里需要的是**一图流的第三方 API Token**，不是国服《明日方舟》的游戏 Token，也不是 Yostar 登录凭据。仅在本地导入、编辑和保存草稿时，仍然不需要 Token。

![一图流个人中心：用户信息下方的第三方 API Token 卡片提供只读和只写 Token 生成按钮](docs/screenshots/yituliu-tokens.png)

每种权限只能保留一个 Token。已有 Token 时，需要先删除旧 Token，再生成新的；旧值随即失效，其他使用它的工具也需要更新。不要分享生成的 Token。

## 写回一图流（可选）

有自己的读写 Token 才使用这一部分。先用只读 Token 读取现有数据；核对 UID、持有数量和练度，下载备份，再点击“检查并写入一图流”并确认。写入后重新读取核对。

**写入会整体替换远端干员列表，不只是当前显示的几行。** 本次发布测试未操作真实账号写入。

Token 只保留在页面内存中，通过本机 `127.0.0.1` 代理发送，不写入浏览器存储或草稿。草稿仍含练度和你填写的个人资料，不要上传到 Issue。

## 常见问题

- **Windows 警告**：CMD 也可能被系统策略或下载信誉检查提示。请确认来源，不要关闭系统防护；本工具不能保证无警告。
- **浏览器没打开**：保留命令窗口，手动访问 `http://127.0.0.1:38471/`。
- **端口被占用**：关闭上一次启动的工具命令窗口，再启动。
- **首次下载失败**：看窗口中的错误，检查网络后重试 Start.cmd。
- **缺少新干员/模组**：先保存草稿，运行 **Update-catalog.cmd**，刷新页面并恢复草稿。“刷新推荐率”只刷新统计。
- **不要直接打开 index.html**：网页需要本地服务，请用 Start.cmd。

## ArkPRTS（实验性）

普通使用不需要它。可选导出器 `导出国际服干员_实验性.cmd` 需要单独安装 Python 3 和 `py -m pip install -U arkprts`，支持 EN / JP / KR 邮箱验证。登录前会要求确认风险。

它访问非官方 Yostar 接口，可能导致游戏掉线，也可能随接口变化失效。默认可用 MAA 或手填；不要分享验证码、Token 或原始账号响应。
