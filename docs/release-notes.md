## Windows download

Download **Yituliu-Workbench-Windows-x64-v3.1.1.zip**, extract it, and double-click **Start.cmd**. The browser opens automatically. Keep the command window open while editing.

Node.js is included. No installation or typed commands are needed. The first launch downloads the public game catalog and needs internet access; the catalog is then reused locally. Save a draft before closing or refreshing the page.

This release is public. No GitHub account is needed to download it.

### Changes

- Added English and Chinese instructions for generating Yituliu read-only and write-only API tokens, with a Personal Center screenshot.
- Published the repository and downloads publicly.

- Added a portable Windows x64 package with checksum-verified Node.js 22.23.2 and license.
- Added Start.cmd and Update-catalog.cmd; game data is downloaded locally instead of redistributed.
- Rewrote English and Chinese guides with annotated screenshots.
- Kept explicit confirmation for whole-roster writes and optional ArkPRTS login.

Windows may still warn about downloaded scripts. The package does not disable Windows security. Real account writes were not tested.

The Source ZIP is for developers and does not include Node.js. SHA256SUMS.txt covers both ZIP downloads.
